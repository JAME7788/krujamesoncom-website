เลือกหัวข้อโครงงาน

ปัญหาที่ต้องการแก้InputProcessOutput

แนวทางโครงงานที่เลือกได้

  • เครื่องเตือนระยะใกล้: ultrasonic sensor + LED หรือ buzzer
  • สถานีวัดอุณหภูมิ: DHT22 + LCD หรือ Serial Monitor
  • ไฟอัตโนมัติตามความมืด: LDR + LED
  • ประตูจำลอง: ปุ่มกดหรือเซนเซอร์ + servo

รายการอุปกรณ์

อุปกรณ์จำนวนหน้าที่ในระบบ

แผนการทดลอง

  1. วาดหรือแปะผังวงจร
  2. เขียนเงื่อนไขการทำงานเป็นภาษาคนก่อนเขียนโค้ด
  3. ทดลองอย่างน้อย 3 ครั้งในสถานการณ์ต่างกัน
  4. บันทึกผลและแก้ไขจุดที่ยังไม่ทำงาน
