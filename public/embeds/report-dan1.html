ออกแบบหน่วยการเรียนรู้และแผนการจัดการเรียนรู้โดยเน้นผู้เรียนเป็นสำคัญตามแนวทาง Active Learning กำหนดจุดประสงค์การเรียนรู้ครบถ้วนทั้งพุทธิพิสัย (K) ทักษะพิสัย (P) และจิตพิสัย (A) ออกแบบกิจกรรมการเรียนรู้ที่มีวิธีการปฏิบัติที่หลากหลาย สอดคล้องกับธรรมชาติของสาระวิทยาการคำนวณและเทคโนโลยี โดยพัฒนากิจกรรมการเรียนรู้ที่ใช้นวัตกรรมเกมมิฟิเคชัน (Gamification) ในแผนประเด็นท้าทาย ชั้น ป.๑ (แผนที่ ๕–๘ รวม ๒๐๐ นาที) อำนวยความสะดวกในการเรียนรู้ มีการจัดลำดับเนื้อหาจากง่ายไปยาก เพื่อให้ผู้เรียนได้ลงมือปฏิบัติจริง ฝึกซ้ำ และพัฒนาสมรรถนะสำคัญเต็มตามศักยภาพ

 เชิงปริมาณ: แผน Active Learning กว่า ๒๕ แผน พร้อมแผนประเด็นท้าทาย ๔ แผน (๒๐๐ นาที)
เชิงคุณภาพ: ผู้เรียนมีส่วนร่วมเกิน ๙๐% มีเจตคติเชิงบวกต่อวิชาเทคโนโลยี
📂 หลักฐาน: เล่มแผน Active Learning, แผนประเด็นท้าทาย ป.๑, สไลด์ Canva
๑.๓ การจัดกิจกรรมการเรียนรู้

ดำเนินการวิเคราะห์ผู้เรียนรายบุคคลก่อนจัดกิจกรรม และจัดการเรียนรู้เชิงรุก (Active Learning) ในห้องปฏิบัติการคอมพิวเตอร์แบบ ๑ คนต่อ ๑ เครื่อง โดยครูทำหน้าที่เป็นผู้อำนวยความสะดวก (Facilitator) และโค้ช ใช้รูปแบบการเรียนรู้โดยใช้เกมเป็นฐาน (Game-Based Learning) และเทคนิคเพื่อนช่วยเพื่อน (Peer Tutoring) เพื่อช่วยเหลือผู้เรียนที่มีความแตกต่างระหว่างบุคคล มีแผนการจัดการเรียนรู้ที่มีองค์ประกอบครบถ้วนนำไปปฏิบัติได้จริง และมีบันทึกหลังการสอนทุกคาบเพื่อประเมินผล K-P-A พร้อมนำผลการจัดกิจกรรม ปัญหา และข้อเสนอแนะมาปรับปรุงพัฒนาแผนการจัดการเรียนรู้และวิธีการสอนในคาบถัดไปอย่างต่อเนื่อง

 เชิงปริมาณ: จัดกิจกรรมครบ ๑๐๐% ตามตารางสอน ๒๓ คาบ/สัปดาห์ ผู้เรียนเข้าเรียนครบ ๑๐๐%
เชิงคุณภาพ: ผู้เรียนมีทักษะปฏิบัติจริง กล้าซักถาม กล้าทดลองแก้ปัญหาด้วยตนเอง

กำหนดและออกแบบเครื่องมือวัดและประเมินผลการเรียนรู้ที่สอดคล้องกับมาตรฐานการเรียนรู้และตัวชี้วัดตามสภาพจริง (Authentic Assessment) โดยใช้เครื่องมือวัดผลที่หลากหลาย ได้แก่ แบบทดสอบก่อนเรียน-หลังเรียน (Pre-test / Post-test), เกณฑ์การประเมินรูบริกส์ (Rubrics) ทักษะปฏิบัติ ๔ ด้าน, แบบสังเกตพฤติกรรมการเรียนรู้และการทำงานกลุ่ม, การตรวจชิ้นงานภารกิจในเกม และสมุดคะแนนดิจิทัล GradeBook K/P/A มีเกณฑ์การวัดและตัดสินผลที่ชัดเจน โปร่งใส และนำผลการประเมินมาสะท้อนกลับ (Feedback) ให้ผู้เรียนทราบจุดเด่นจุดพัฒนาเพื่อปรับปรุงตนเองทันที

เชิงคุณภาพ: ผลประเมินเที่ยงตรง โปร่งใส นำข้อมูลมาซ่อมเสริมพัฒนาผู้เรียนได้ตรงจุด
📂 หลักฐาน: Pre/Post-test เมาส์ ป.๑, รูบริกส์ ๔ ด้าน, ปพ.๕ ดิจิทัล, สถิติ Quizizz

ศึกษา วิเคราะห์ สภาพปัญหาการเรียนรู้ของผู้เรียนชั้นประถมศึกษาปีที่ ๑ ด้านทักษะการใช้เมาส์ ซึ่งพบปัญหาความแข็งแรงของกล้ามเนื้อมัดเล็กและการประสานสัมพันธ์ระหว่างสายตากับมือ จึงได้ออกแบบและดำเนินการแก้ปัญหาตามวงจร ADDIE Model ร่วมกับแนวคิด Active Learning และ Gamification จัดทำวิจัยในชั้นเรียน เรื่อง 'การพัฒนาทักษะปฏิบัติการใช้เมาส์ด้วยเกมมิฟิเคชันร่วมกับ Active Learning วิชาวิทยาการคำนวณ ชั้นประถมศึกษาปีที่ ๑ (๑๑ คน)' และสรุปผลการแก้ปัญหาอย่างเป็นรูปธรรมด้วยสถิติทดสอบ Paired t-test พบว่าคะแนนเฉลี่ยหลังเรียน (๑๗.๕๕) สูงกว่าก่อนเรียน (๘.๐๙) อย่างมีนัยสำคัญทางสถิติที่ระดับ .๐๑ (t = ๓๘.๒๓*, df = ๑๐, p < .๐๐๑) และผู้เรียนผ่านเกณฑ์ร้อยละ ๖๐ ครบทั้ง ๑๑ คน (๑๐๐%)

ศึกษา วิเคราะห์ สภาพปัญหาการเรียนรู้ของผู้เรียนชั้นประถมศึกษาปีที่ ๑ ด้านทักษะการใช้เมาส์ ซึ่งพบปัญหาความแข็งแรงของกล้ามเนื้อมัดเล็กและการประสานสัมพันธ์ระหว่างสายตากับมือ จึงได้ออกแบบและดำเนินการแก้ปัญหาตามวงจร ADDIE Model ร่วมกับแนวคิด Active Learning และ Gamification จัดทำวิจัยในชั้นเรียน เรื่อง 'การพัฒนาทักษะปฏิบัติการใช้เมาส์ด้วยเกมมิฟิเคชันร่วมกับ Active Learning วิชาวิทยาการคำนวณ ชั้นประถมศึกษาปีที่ ๑ (๑๑ คน)' และสรุปผลการแก้ปัญหาอย่างเป็นรูปธรรมด้วยสถิติทดสอบ Paired t-test พบว่าคะแนนเฉลี่ยหลังเรียน (๑๗.๕๕) สูงกว่าก่อนเรียน (๘.๐๙) อย่างมีนัยสำคัญทางสถิติที่ระดับ .๐๑ (t = ๓๘.๒๓*, df = ๑๐, p < .๐๐๑) และผู้เรียนผ่านเกณฑ์ร้อยละ ๖๐ ครบทั้ง ๑๑ คน (๑๐๐%)
