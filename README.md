# Kru James Soncom Classroom

เว็บห้องเรียนเทคโนโลยีสำหรับนักเรียนระดับ ป.1-ม.3 ครอบคลุมบทเรียน สไลด์ เกมฝึก
ห้องเรียน 3D การบ้าน การเช็กชื่อ และระบบวัดผล K/P/A ของครูในระบบเดียว

อัปเดตเอกสารล่าสุด: **23 กันยายน 2569**

## ความสามารถหลัก

- หลักสูตรวิทยาการคำนวณและการออกแบบเทคโนโลยีตามตัวชี้วัด ว 4.1 และ ว 4.2
- แผนเทคโนโลยี/วิทยาการคำนวณ ป.1-ม.3 ชั้นละ 40 แผน รวม 360 แผน โดย 1 แผนตรงกับ 1 คาบเรียน
- ศูนย์ "คาบเรียนวันนี้" สำหรับเช็กชื่อ เปิดสไลด์ เปิดบทเรียน ควิซ เกม และมอบหมายงาน
- กำหนดการสอน บันทึกวันที่สอนจริง สถานะเลื่อนสอน/สอนชดเชย และบันทึกหลังสอน
- คะแนน K/P/A จากแบบทดสอบ เกม การบ้าน งานปฏิบัติ การเข้าเรียน และการประเมินของครู
- คลังข้อสอบแบ่งง่าย/ปานกลาง/ยาก สุ่มชุด 10 ข้อ และวิเคราะห์ผลรายข้อ
- การบ้านผ่านลิงก์ เช่น Canva พร้อมรูบริก K/P และการตรวจรายคน
- เกมในเว็บ 36 เกม และห้องเรียน 3D
- ระบบเผยแพร่เนื้อหา เวอร์ชันย้อนหลัง ประวัติการแก้ไข และสิทธิ์ admin/teacher/viewer
- Firebase Firestore เป็นแหล่งข้อมูลร่วม พร้อม local cache เมื่อเครือข่ายมีปัญหา
- บัญชีแยก 3 ประเภท: นักเรียนจริง, ผู้ทดลองภายนอก และครู/ผู้ดูแล
- ผู้ทดลองกรอกเฉพาะชื่อ เก็บสถิติการเผยแพร่แยกจากทะเบียน และไม่เก็บคะแนน/เช็กชื่อ
- แบบประเมินรายบุคคลที่ครูยืนยันแล้วอยู่ใน Firebase และสคริปต์เติมข้อมูลจะไม่เขียนทับ
- โปรไฟล์รายคนเชื่อมแบบสมรรถนะ คุณลักษณะ อ่าน–คิด–เขียน ค่านิยม และร่าง K/P/A ตามคาบที่สอนจริง
- ตารางสอน ศูนย์คาบเรียน เช็กชื่อ คะแนน และบันทึกหลังสอนใช้ `TeachingSession` ชุดเดียว พร้อมข้ามวันงดเรียนปี 2569
- เครื่องมือวิจัยในชั้นเรียน WBI + ADDIE สร้างบทคัดย่อและเนื้อหาครบ 5 บทจากข้อมูล K/P/A จริง แก้ไขทีละบทและทำงานต่อจากแคชได้เมื่อ Firebase ช้า
- หลังแผนเทคโนโลยี ป.1 แสดงร่างรายแผนและข้อมูลที่บันทึกจริง เลือกวันสอนตามกำหนดการ และไม่แสดงตัวเลขผ่าน/K/P/A จนกว่าจะมีหลักฐาน
- หน้าแผนเทคโนโลยี ป.1 ดาวน์โหลด Word ไฟล์รวม 40 แผนพร้อมบันทึกหลังสอนล่าสุดจาก Firebase ได้ โดยใช้แบบเอกสารโรงเรียน A4 ฟอนต์ TH SarabunPSK และหัวข้อประเมินครบ 15 ส่วน พร้อมระบุแผนที่ยังไม่มีบันทึกอย่างชัดเจน

## เส้นทางสำคัญ

| URL | การใช้งาน |
|---|---|
| `/` | หน้าแรกและเข้าสู่ระบบนักเรียน |
| `/courses` | รายวิชาและหน่วยการเรียนรู้ |
| `/games` | เกมฝึกทักษะทั้งหมด |
| `/world` | ห้องเรียน 3D |
| `/homework` | งานและการบ้านของนักเรียน |
| `/dashboard` | ความก้าวหน้าของนักเรียน |
| `/admin` | แผงควบคุมครู 31 เมนู รวมสถิติผู้ทดลองภายนอก |
| `/admin?tab=gradebook` | สมุดเก็บคะแนน K/P/A ของครู |
| `/live/host` | ครูเปิดควิซสด |
| `/live` | นักเรียนเข้าร่วมควิซสด |

## การทำงานของคะแนน

1. นักเรียนเข้าสู่บทเรียน เกม แบบทดสอบ หรือส่งงาน
2. ระบบบันทึก progress และหลักฐานกลางใน `learningEvidence`
3. หลักฐานระบุแหล่งที่มา ตัวชี้วัด วิชา ห้องเรียน เวลา และประเภท K/P/A
4. คะแนนกิจกรรมไม่เกินคะแนนเต็ม โดยกิจกรรมในคาบมีน้ำหนักสูงกว่านอกคาบ
5. ครูตรวจ แก้ไข หรือเพิ่มงานภายนอกได้จากสมุดคะแนน K/P/A
6. การแก้ไขสำคัญถูกบันทึกใน `teacherAuditLogs`

บัญชี `admin_teacher_account` และ id ที่ขึ้นต้นด้วย `external_visitor_` จะถูกปฏิเสธก่อนเขียน
`students`, `progress`, `learningEvidence` และ `homeworkSubmissions` ทั้งในโค้ดและ Firestore Rules

## ใช้งานแผงควบคุมครู

- เลือกงานจากเมนูด้านซ้ายบนคอม หรือรายการเลือกเมนูบนมือถือ
- เมื่อเปลี่ยนงาน URL จะระบุ `?tab=` ของหน้านั้น จึงคัดลอกลิงก์หรือใช้ปุ่มย้อนกลับของเบราว์เซอร์ได้
- แถบใต้หัวหน้าแอดมินแสดงสถานะการโหลดและเวลาอัปเดตล่าสุด หากเชื่อมต่อข้อมูลนักเรียนไม่สำเร็จ ระบบจะแจ้งเตือนและคงข้อมูลเดิมบนจอ ให้กด **รีเฟรช** อีกครั้ง
- ในสมุดคะแนน ช่อง K ที่ครูกรอกเองจะบันทึกเมื่อกด Enter หรือออกจากช่อง ช่องว่างหมายถึงยังไม่กรอก ส่วน `0` คือให้คะแนนศูนย์จริง
- เลือกปีการศึกษาและภาคเรียนก่อนกรอก ระบบแยกข้อมูลและไฟล์ส่งออกตามช่วงเวลา ข้อมูลเดิมอยู่ที่ปี 2569 ภาคเรียน 1
- เมื่อคะแนนครบ ให้กด **ส่งรอยืนยัน** แล้ว **ปิดผล** ระบบจะเก็บ snapshot และรุ่นเกณฑ์ หากเปิดแก้ไขใหม่ต้องระบุเหตุผล
- บัญชีบทบาท `viewer` เข้าดูได้เฉพาะภาพรวม สถิตินักเรียน และพัฒนาการรายคน แม้เปิดลิงก์ตรงไปยังเมนูอื่น

## Firebase

คัดลอกค่าที่ต้องใช้จาก `.env.example` ไปยัง environment ของเครื่องหรือ Vercel
โดยห้าม commit รหัสผ่านหรือ secret จริงลง repository

ระบบเปิด Firebase Auth และสร้าง `teacherProfiles`/บทบาท `admin` สำหรับครูแล้ว
แต่ยังคงมี legacy admin fallback จนกว่าจะตั้งรหัสผ่านจากอีเมลและทดสอบบัญชีจริงสำเร็จ
ก่อนใช้ข้อมูลนักเรียนจริงผ่านอินเทอร์เน็ตสาธารณะ ต้องเปิด App Check และตรวจ
Firestore Rules ตาม [SECURITY.md](SECURITY.md)
