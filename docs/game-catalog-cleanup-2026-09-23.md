# การคัดกรองหน้าเกม วันที่ 23 กันยายน 2569

## สิ่งที่เอาออกจากหน้าเกม

- รายการจาก `learningResources` หมวด programming และ computational เพราะในกลุ่มเดียวกันมีทั้งคอร์ส เครื่องมือเขียนโปรแกรม และบทเรียน จึงไม่ควรเรียกทุกชิ้นว่าเกม
- Kru-Com Arcade 104 ด่าน รวมถึงการ์ด 409 รายการจาก Google Sheets เพราะตัวด่านสร้างจากชื่อและเนื้อหาในเอกสารหรือ PDF โดยไม่ได้มีการตรวจรูปแบบการเล่นแต่ละรายการ

## เกณฑ์ที่ใช้กับแคตตาล็อกปัจจุบัน

เกมที่แสดงใน `/games` ต้องมีเส้นทางภายในเว็บ มีหน้าการเล่นเฉพาะ และมีการโต้ตอบเพื่อบรรลุเป้าหมายของเกม รายการอ่าน คอร์ส เครื่องมือ และเอกสารไม่อยู่ในแคตตาล็อกเกม

หลังคัดกรอง แคตตาล็อกเหลือ 36 เกม ข้อมูลชีตและภารกิจเดิมยังเก็บไว้เป็นแหล่งอ้างอิง แต่ไม่มีเส้นทางสาธารณะจากหน้าเกม
