# ความเสถียรและหน้าตาของส่วนกลางเว็บ

วันที่ 10 กันยายน 2569

## ปรับในรอบนี้

- ช่องค้นหาใช้ native dialog แทน overlay เดิม โฟกัสเริ่มในช่องค้นหาและอยู่ในชั้น modal ของเบราว์เซอร์
- ยกเลิกตัวหน่วงเวลาโฟกัส ปิดด้วยปุ่มหรือ Escape ได้ และเลื่อนผลที่เลือกด้วยแป้นลูกศรให้อยู่ในพื้นที่มองเห็น
- ไม่ส่งคำค้นระหว่างการประกอบตัวอักษรด้วย IME
- หน้าเริ่มค้นหามีทางเข้าคอร์ส เกม และแหล่งเรียนรู้ แทนข้อความอธิบายวิธีใช้งานยาว
- ปรับหัวข้อ ระยะห่าง สีรายการที่เลือก ความสูงป๊อปอัป และข้อความบนมือถือ พร้อมสีโหมดมืดและลดภาพเคลื่อนไหวตามการตั้งค่าเครื่อง
- เพิ่ม ErrorBoundary รายหน้าภายใน Layout เพื่อไม่ให้ข้อผิดพลาดการแสดงผลของหน้าลูกแทนที่เมนูทั้งเว็บ เปลี่ยนเส้นทางแล้วเริ่มขอบเขตใหม่
- ซ่อนข้อความ error ภายในจากหน้า production และให้ปุ่มกู้คืนตัดบรรทัดได้บนจอเล็ก

## ตรวจสอบ

- ชุดทดสอบเดิม 55 ไฟล์ 661 ข้อผ่าน
- เพิ่มและรัน regression contracts 3 ข้อผ่าน สำหรับ native dialog, page boundary และการซ่อนรายละเอียด error
- Build ผ่าน และ ESLint ไฟล์ที่แก้ผ่านก่อนเพิ่มการตรวจ IME
- ทดลองหน้าค้นหาบนคอมและมือถือ 390 พิกเซล: modal จริง, ช่องค้นหารับโฟกัส, ผล Python แสดง, ป๊อปอัปกว้างประมาณ 358 พิกเซลและไม่ล้นจอ
- เปิดซ้ำและยืนยันปิดได้ มีเครื่องมือ browser timeout หนึ่งครั้งระหว่างทดสอบ จึงตรวจซ้ำจนปิดแล้วสถานะ modal เป็น false

## ข้อจำกัด

เป็นการยกระดับส่วนกลาง ไม่ใช่การรับรองว่าไม่มีบั๊กทั้งระบบ การกู้คืน error ตรวจเชิงโครงสร้าง ยังไม่ได้จงใจทำหน้าจริงให้ล้ม และยังไม่ได้ทดสอบ dialog ระหว่างเกม fullscreen จริงในรอบนี้ ไม่มีการเขียนข้อมูลนักเรียนหรือเปลี่ยนคะแนน ยังไม่ได้ขึ้น Vercel
