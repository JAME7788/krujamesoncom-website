# รายงานตรวจและปรับปรุงเกม 7-9 กันยายน 2569

## ขอบเขต

ตรวจจาก workspace ในเครื่องด้วยบัญชีผู้เยี่ยมชม ไม่ใช้บัญชีนักเรียนจริง ไม่แก้คะแนนหรือข้อมูลนักเรียน และไม่ได้ deploy ในรอบนี้

- ตรวจเปิดเส้นทางเกม 37 เส้นทางจากลิงก์ในคลังเกมจริง ที่ขนาด 1366 x 900 และ 390 x 844
- ทุกเส้นทางแสดงเนื้อหาเกม ไม่พบภาพ img ที่โหลดล้มเหลวในการตรวจหน้าแรกบนจอคอม
- พบหน้าล้นแนวนอนบนมือถือ 4 เกม แก้และตรวจซ้ำแล้ว: Robot Maker, Cyber Shield, Sorting Dash, Kru-Com Arcade
- การตรวจเปิดหน้าไม่เท่ากับเล่นครบทุกด่าน ทุกธีม หรือทุกเงื่อนไขจบเกม

## สิ่งที่แก้

| ส่วน | ปัญหาและการแก้ |
| --- | --- |
| ป๊อปอัปบทเรียนร่วม | เปลี่ยนเป็น native dialog เพื่อใช้ชั้น modal ของเบราว์เซอร์ กักโฟกัสและป้องกันคีย์บอร์ดหลุดไปควบคุมเกม เลื่อนเนื้อหาภายในได้โดยปุ่มปิดและเริ่มเล่นยังอยู่ในจอ รองรับ reduced motion |
| การบันทึกเกมร่วม | ให้เหรียญหลังบริการบันทึกผลตอบกลับสำเร็จ แยกตัวป้องกันการบันทึกซ้ำตามผู้ใช้ เกม และภารกิจ ไม่ปิดกั้นภารกิจถัดไปในหน้าเดิม ปลดล็อกให้ลองใหม่เมื่อบันทึกล้มเหลว |
| ตัวหน่วงเวลา | เพิ่ม useGameTimers และ createGameTimers ยกเลิก callback เก่าเมื่อออกจากเกม เปลี่ยนช่วงเล่น หรือเริ่มใหม่ในเกมที่นำไปใช้ |
| Quick Answer | ล็อกคำตอบ ข้าม และพักระหว่างแสดงผล ป้องกันข้อกับคำตอบคลาดเคลื่อน ยกเลิกผลเฉลยเก่าเมื่อเริ่มรอบใหม่ จบเกมครั้งเดียว และไม่เริ่มตัวจับเวลาใหม่ทุกครั้งที่คะแนนเปลี่ยน |
| Stroop Color | แก้เวลารวมที่เคยบวก 60 วินาทีซ้ำ ป้องกันจบเกมซ้ำจากคำตอบกับหมดเวลาชนกัน ล้างคะแนนด่านสองเมื่อเริ่มใหม่ และไม่สร้างรายชื่อ/คะแนนตัวอย่างแทรกในอันดับจริงเมื่อเปิดครั้งแรก |
| Snake | สุ่มอาหารจากช่องว่างแบบมีจุดจบ ป้องกันค้างเมื่อเต็มกระดาน อนุญาตเดินเข้าช่องหางที่กำลังขยับออก รับการเลี้ยวหนึ่งครั้งต่อจังหวะ และย้ายผลข้างเคียงออกจาก state updater |
| Bug Catcher | เป้าหมายแต่ละตัวถูกจับหรือหมดอายุได้ครั้งเดียว ป้องกันหักชีวิตซ้ำ ยกเลิกเวลาเป้าหมายค้างจากรอบเก่า และล็อกการจบเกม |
| Device Match / Safety / Step Sort | ยกเลิกคำสั่งเปลี่ยนข้อหรือ feedback ที่ค้างอยู่เมื่อรีสตาร์ตหรือออกจากเกม |
| Situation Reaction | ใช้เวลาเริ่มข้อจริงคำนวณเวลาคงเหลือ ล็อกการตอบพร้อม timeout และย้ายการเปลี่ยนข้อออกจากตัวอัปเดตจำนวนชีวิต |
| PC Builder | ป้องกันวางชิ้นส่วนซ้ำและปั๊มคะแนนด้วยการสลับด่าน ล้างตัวหน่วงเวลาเมื่อเปลี่ยนด่าน/เริ่มใหม่ บันทึกจบเมื่อได้ชิ้นส่วนครบทุกด่าน และปิด AudioContext หลังเสียงจบ |
| Kru-Com Arcade | ผูกเวลาค้างกับภารกิจ ป้องกัน feedback จับคู่ผิดล้างตัวเลือกใหม่ ล็อกลำดับที่แก้สำเร็จแล้ว แยกการบันทึกแต่ละภารกิจ และคำนวณ XP/ดาวของ quiz จากสัดส่วนคำตอบถูก ไม่ให้เต็มเมื่อตอบผิดทั้งหมด |
| Flowchart Bingo | สร้างกระดานเริ่มต้นพร้อมคำใบ้ ยกเลิก callback เมื่อเริ่มใหม่ ล็อกการข้ามและการกาซ้ำระหว่างเปลี่ยนคำใบ้ |
| Sorting Dash | แก้หมดเวลาแล้วหักชีวิตซ้ำจนติดลบด้วยการย้ายผลข้างเคียงออกจาก state updater ล็อกจบเกมและคำตอบซ้ำ ใช้เวลาสิ้นสุดของแต่ละข้อ ยกเลิก feedback เก่าเมื่อเริ่มใหม่ พักเวลาขณะเปิด dialog บทเรียน และแสดงคอมโบสูงสุดแทนคอมโบสุดท้าย |
| มือถือ | ปรับหัวและแถบสถานะของ 4 เกมที่ล้นขอบ จัดการ์ด Sorting Dash ไว้แถวบนและช่องคำตอบสองช่องไว้ด้านล่าง โดยคงสีและภาพเดิม |

## ผลทดสอบอัตโนมัติ

- `npm test`: 48 ไฟล์ 557 ข้อ ผ่านในรอบล่าสุด ณ เวลาจัดทำรายงาน
- `npm run qa:games`: 370 checks ผ่าน
- `npm run build`: ผ่าน TypeScript และ production bundle
- ESLint เฉพาะไฟล์ TS/TSX และชุดทดสอบที่แก้ในรอบนี้: ผ่าน
- เพิ่ม 9 unit tests: การยกเลิก timer 3 ข้อ และตรรกะงู 6 ข้อ
- จำนวนรวมรวมการทดสอบเดิมของระบบด้วย ไม่ใช่ 557 กรณีที่ทดลองเล่นผ่านเบราว์เซอร์

## ทดลองเล่นผ่านเบราว์เซอร์

- Quick Answer: หมดเวลา 20 วินาที แสดงผลจบ; ข้ามถูกล็อกระหว่างเฉลย; กลับตั้งค่าและเริ่มใหม่ทันทีแล้วกลับข้อ 1 คะแนน 0
- PC Builder: วางจอภาพได้ 100 คะแนน; สลับด่านกลับมาวางเดิมคะแนนยังเป็น 100; เริ่มใหม่กลับ 0
- Stroop Color: ตอบถูกได้ 2 คะแนน ปุ่มล็อกระหว่าง feedback; ทดสอบปล่อยหมดเวลาทั้งสองด่าน ไปหน้าสรุปได้และแสดงรายการผู้ทดสอบครั้งเดียว ไม่ยืนยันค่ารวม 120 วินาทีผ่าน UI เพราะหน้าสรุปไม่แสดงเวลา
- Sorting Dash: ก่อนแก้พบชีวิต -1 หลังหมดเวลา; หลังแก้ปล่อยหมดเวลาจบที่ 0 และเริ่มใหม่กลับ 3; ตรวจภาพและตำแหน่งบนมือถือว่าการ์ดอยู่เหนือสองช่องคำตอบ ไม่ทับกันและไม่ล้นแนวนอน
- Logic Gates: ตรวจ screenshot ป๊อปอัปที่ 390 x 844; ปุ่มเริ่มเล่นอยู่ในจอ กดปิดได้ และตรวจ DOM ว่าเป็น native modal
- Digital City Quest: เริ่มเกมจอเดียว เปิดคู่มือในโหมดขยายจอ ทอยและเดินก่อนคำถาม ตอบถูก และเปิดโครงการสำเร็จพร้อมป๊อปอัปผลภารกิจ
- โหมดขยายจอของ Digital City Quest แสดงได้ในเบราว์เซอร์ทดสอบ แต่ `document.fullscreenElement` ไม่ได้ยืนยัน native fullscreen จึงไม่ถือเป็นการทดสอบ native fullscreen ครบทุกเบราว์เซอร์

## สิ่งที่ยังไม่ยืนยัน

- ไม่ได้เล่นครบทุกด่านของทั้ง 37 เกม และไม่ได้ตรวจเนื้อหาทุกภารกิจย่อยใน Kru-Com Arcade ผ่าน UI
- ยังไม่ได้ทดสอบห้องออนไลน์กับเครื่องจริงหลายเครื่อง การหลุดเครือข่าย reconnect เจ้าของห้องออก และการกลับเข้าห้องระหว่างคำถามในรอบนี้
- ไม่ได้เขียนผลทดลองลงบัญชีนักเรียนหรือพิสูจน์การซิงก์ Firebase ด้วยคะแนนจริงของนักเรียน
- ยังไม่ได้ตรวจ canvas-pixel ของเกม 3D ทุกเกม หรือวัดประสิทธิภาพบนคอมพิวเตอร์โรงเรียนรุ่นเก่า
- การป้องกันบันทึกซ้ำใน hook มีอายุเท่าหน้าเกมที่เปิดอยู่ ส่วนการป้องกันรายการคะแนนซ้ำข้ามการเปิดหน้าใช้กลไก dedup ของบริการเดิม
- ไม่รับรองว่าไม่มีบั๊กเหลือทั้งหมด และไม่ถือว่ารายงานนี้ยืนยันว่าพร้อมแข่งขันทุกสถานการณ์
