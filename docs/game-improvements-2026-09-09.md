# พัฒนาเกมและแก้บั๊ก 9 กันยายน 2569

## ขอบเขตรอบนี้

ต่อยอดจากการตรวจเปิด 37 เส้นทางใน `game-audit-2026-09-09.md` และการแก้ส่งคะแนนใน `game-score-connection-2026-09-09.md` รอบนี้ปรับโดยตรง 7 เกม ไม่ใช่การรับรองว่าเล่นครบทุกด่านของทุกเกมแล้ว

## การแก้ไข

- Binary, Logic Gates, Pixel Art, Search Smart, Algorithm Sorter และ Pattern: กันรับคำตอบหรือเปลี่ยนข้อซ้ำก่อนหน้าจออัปเดต และส่งคะแนนรวมพร้อมคะแนนเต็มจริงเมื่อจบรอบ
- หยุดส่งคะแนนข้อแรกเป็นผลจบเกมในเกมที่เคยบันทึกก่อนจบรอบ
- อ่านและเขียนสถิติอย่างปลอดภัยเมื่อเบราว์เซอร์ไม่ให้ใช้พื้นที่เก็บข้อมูล หรือค่าที่เคยเก็บไม่ถูกต้อง
- Memory Match: เลือก 4, 6 หรือ 8 คู่ พักเวลาและซ่อนการ์ดขณะพัก กลับมาเล่นต่อได้ ใช้ปุ่มการ์ดที่รองรับคีย์บอร์ด
- Memory Match: แยกสถิติตามธีมและจำนวนคู่ ป้องกันเปิดใบที่สามระหว่างเฉลย ป้องกันผลจากรอบเก่าหลังเริ่มใหม่ และส่งจำนวนคู่ที่สำเร็จแทนจำนวนครั้งที่ลองผิด
- คงภาพพื้นหลังและธีมเกมเดิมไว้ พร้อมปรับปุ่มการ์ดและข้อความขณะพัก

คะแนนของเกมที่ให้ลองตอบจนถูกเป็นคะแนนการทำกิจกรรมสำเร็จ ไม่ใช่ร้อยละความถูกต้องในการตอบครั้งแรก ไม่มีการแก้คะแนนย้อนหลังหรือเขียนข้อมูลนักเรียนจริงในรอบนี้

## ผลตรวจ

- ชุดทดสอบรวม 53 ไฟล์ 610 ข้อผ่าน เพิ่ม 21 ข้อจากรอบก่อน
- ตรวจเนื้อหาเกม 370 จุดผ่าน
- สร้างเว็บสำหรับใช้งานจริงผ่าน และตรวจรูปแบบโค้ดไฟล์ที่แก้ในรอบนี้ผ่าน
- ทดลอง Memory Match บนคอม: จบ 4 คู่ใน 4 ครั้ง แสดงผลชนะและสถิติ พักแล้วเวลาไม่เดินและการ์ดถูกซ่อน เล่นต่อได้
- ทดลองบนมือถือกว้าง 390: 4/6/8 คู่มีการ์ด 8/12/16 ใบตามลำดับ ไม่มีการล้นแนวนอน
- เริ่มใหม่ระหว่างรอเฉลย: จำนวนครั้งและการ์ดกลับเป็นรอบใหม่ หลัง callback เดิมผ่านไปไม่มีการ์ดค้างเปิดหรือจับคู่จากรอบเก่า
- การกันกดซ้ำและการส่งคะแนนของหกเกมตรวจด้วยชุดทดสอบตรรกะและโครงสร้างโค้ด ยังไม่ได้เล่นจบทุกเกมผ่านหน้าจอในรอบนี้
